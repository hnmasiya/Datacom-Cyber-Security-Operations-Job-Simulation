**Datacom Cyber Security Operations Job Simulation — Forage**

## Overview
This repository documents my completed Datacom Cyber Security Operations Job Simulation on the Forage platform.

The simulation provided practical, scenario-based cybersecurity work focused on protecting clients, investigating cyberattacks, documenting findings, and assessing cybersecurity risk.

> **Important:** This was a Forage virtual job simulation / virtual experience program. It was not employment with Datacom.

## Tasks
- **Task 1 — Cyberattack Investigation:** investigated a simulated ransomware incident, documented findings, attack indicators, response priorities, and security recommendations.
- **Task 2 — Cybersecurity Risk Assessment:** assessed major cybersecurity risks for a simulated retail organization using a 5×5 likelihood/consequence approach and developed mitigation priorities.
